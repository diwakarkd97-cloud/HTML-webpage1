# Diwakar - Personal Portfolio Webpage

A clean, semantic personal profile webpage built with HTML5, highlighting background information, core technical skills, and contact details.

---

##  Features

- **Semantic HTML5:** Built using semantic markup including `<header>`, `<main>`, and `<section>`.
- **Responsive Meta Tags:** Includes standard viewport and charset meta tags for browser compatibility across devices.
- **Direct Contact Links:** Uses the `tel:` protocol to enable one-click phone dialing from mobile devices.

---

##  Tech Stack

- **Markup:** HTML5
